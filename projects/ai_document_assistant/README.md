# AI Document Assistant using Endee Vector Database

## Live Demo

You can try the live application here:

https://endee-ai-project.streamlit.app/

## Project Overview

This project demonstrates a Semantic Search and Retrieval-Augmented Generation (RAG) system using the Endee Vector Database.

Users can enter queries, and the system retrieves the most relevant documents using vector similarity.

## Technologies Used

- Python
- Streamlit
- Endee Vector Database
- Sentence Transformers

## How to Run Locally

1. Clone the repository
2. Install dependencies

pip install -r requirements.txt

3. Run the application

streamlit run app.py

4. Open browser

http://localhost:8501
